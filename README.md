# Quick Table ⚡

A simple and responsive **Multiplication Table Generator** built with HTML, CSS, JavaScript, Bootstrap, and jQuery.

Enter a number and select a range to quickly generate its multiplication table.

## ✨ Features

- 🔢 Generate multiplication tables instantly
- 📊 Select a custom table range
- ⚡ Fast and interactive interface
- 📱 Responsive design
- 🎨 Clean and user-friendly UI
- 🧩 Uses Bootstrap for responsive styling
- ⚙️ Uses jQuery for interactive functionality

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery
